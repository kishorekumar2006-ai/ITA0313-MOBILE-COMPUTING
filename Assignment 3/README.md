# Mobile Computing – Assignment 3 (CO3)
## Python code, figures and supporting files for GitHub

This repository is for **Assignment 3 – CO3** (pair work, Q1–Q7), not Assignment 2.

### Contents
- `src/generate_routing_comparison.py` – Python source used to regenerate the DSDV/AODV routing trend figures.
- `figures/` – supporting figures for wireless mobility, Mobile IP, cellular/ad hoc networks, emergency communication and routing performance.
- `results/routing_comparison_illustrative.csv` – tabulated DSDV/AODV trend values used in the teaching-model comparison.
- `docs/Assignment_3_CO3_Completed_Report.docx` – completed report.
- `docs/Assignment_3_CO3_Completed_Report.pdf` – PDF copy of the report.
- `docs/methodology_and_limitations.md` – explanation of the illustrative model and limits.
- `docs/group_contribution_template.md` – pair-work contribution record template.

### Install and run
Python 3.9 or newer is recommended.

```bash
python -m pip install -r requirements.txt
```

Run from the repository root:
```bash
python src/generate_routing_comparison.py
```

The script regenerates the three DSDV/AODV trend charts (`routing_overhead.png`, `routing_delay.png`, and `routing_pdr.png`) in the current working directory. Move the generated images into `figures/` if you want to replace the included copies.

### GitHub upload
1. Extract this ZIP.
2. Open the extracted folder in VS Code.
3. Create a new GitHub repository, e.g. `mobile-computing-assignment-3-co3`.
4. Upload the **contents of this folder** (not just the ZIP file).
5. Share the repository URL with your faculty.

Optional commands:
```bash
git init
git add .
git commit -m "Add Mobile Computing Assignment 3 CO3 files"
git branch -M main
git remote add origin https://github.com/YOUR-USERNAME/mobile-computing-assignment-3-co3.git

```
Replace the username and URL with your actual GitHub repository details.

### Academic integrity note
The charts and trend values are **illustrative teaching-model outputs**, not measurements from a real wireless network or packet-level NS-3/OMNeT++ simulation. The included source script regenerates the DSDV/AODV routing trend charts only; the other figures are supplied as supporting report illustrations. Do not claim that all figures are regenerated by this one script. Review the methodology note and ensure both group members can explain the figures, assumptions and code.
